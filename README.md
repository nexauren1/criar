# ForgeKit — Developer Landing Page Template

ForgeKit is a polished, responsive landing page starter for developers, SaaS products, startups and digital teams.

## Included

- Responsive HTML5 landing page
- Dark/light theme toggle
- Mobile navigation
- Hero, features, workflow, pricing, FAQ and CTA sections
- Custom 404 page
- Accessibility-focused foundation
- SEO-ready metadata
- No framework and no build step
- GitHub Pages workflow

## Quick start

Open index.html in a browser. Edit index.html for content, then edit assets/css/style.css for the visual system. Update links and deploy to any static host.

## Project structure

- index.html
- 404.html
- assets/css/style.css
- assets/js/main.js
- docs/customization.md
- product/payhip-listing.md
- .github/workflows/pages.yml
- .nojekyll
- LICENSE.md
