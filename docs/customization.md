# ForgeKit Customization Guide

## Brand

Replace ForgeKit in index.html. Also update the title, description and Open Graph metadata.

## Colors

The first block of assets/css/style.css contains design tokens for the page background, surfaces, text, accents, spacing feel and shadows. Change these variables to create a new visual identity quickly.

## Content

The main sections are Hero, Features, Workflow, Pricing, FAQ, CTA and Footer. Delete, duplicate or reorder them as needed.

## Links

Replace placeholder destinations with your app, documentation, checkout, social profile or contact form. The template does not bundle a payment processor.

## Theme

The theme toggle is handled by assets/js/main.js and saved locally in the browser under the key forgekit-theme.

## Publishing

This is a static site. It can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages or regular web hosting without a build step.

## Launch checklist

Replace the placeholder email address, GitHub URL, pricing claims and product copy. Test mobile navigation, keyboard focus, all links and the final deployed URL.
