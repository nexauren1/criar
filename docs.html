Documentation

Customize it without fighting the code.

Branding, content, motion, processing and deployment are all documented around the actual file structure.

Quick startBrandingProcessingDeployment

01 · QUICK START

Open. Edit. Publish.

No npm install and no build step. Edit the HTML, CSS and JavaScript, then upload the folder to static hosting.

terminal
$ open index.html
$ edit assets/css/style.css
$ publish

02 · BRANDING

Change the visual identity in one place.

Edit the design tokens at the top of assets/css/style.css to change accents, surfaces, text, radii and shadows.

AccentAccent 2BackgroundSuccess

03 · PROCESSING

Turn the demo into your actual product.

The Demo Lab is intentionally local and deterministic. Replace the score calculation in assets/js/main.js with your API call, browser utility or application logic.

04 · DEPLOYMENT

Static hosting is enough.

The included GitHub Pages workflow can publish the site without a build pipeline. The same folder works on Netlify, Vercel, Cloudflare Pages and traditional web hosting.
