Documentation

Change the identity without fighting the code.

The documentation page is separate from marketing so buyers can jump directly into setup and customization.

Quick startBrandingDemo logicDeployment

01 · QUICK START

Open. Edit. Publish.

No package install is required. Edit the HTML, update the shared CSS tokens, and publish the folder to static hosting.

terminal
$ open index.html
$ edit assets/css/style.css
$ publish

02 · BRANDING

Use the shared design system.

Colors, surfaces, radii, text and shadow values live in :root at the top of the stylesheet. Changing those tokens updates the entire product.

03 · DEMO LOGIC

Replace the sample processor.

The Demo Lab calculates a sample score locally. Replace that function with your own browser-side logic, API call or application state.

04 · DEPLOYMENT

Use any static host.

The project is compatible with GitHub Pages and other static hosting because there is no build step.
